# Pokédex Web App

A clean, responsive Pokédex web application built from scratch using **React** and custom **CSS**. I created this project to practice working with RESTful APIs, asynchronous JavaScript, and dynamic state management by fetching real-time Pokémon data from the [PokéAPI](https://pokeapi.co).

## Live Demo

[View Live Project] https://pokedex-xk5m.onrender.com/

## Features

- **Real-Time API Integration:** Fetches live Pokémon data including official artwork, types, abilities, height, weight, and base stats.
- **Search Functionality:** Quickly look up any Pokémon by its name or Pokédex ID.
- **Custom Styling:** Built entirely with pure CSS without any external UI frameworks or component libraries.
- **Responsive Layout:** Designed to work smoothly on both desktop and mobile screens.

## Built With

- **React** – Frontend library for building the user interface and managing state.
- **CSS3** – Custom styling, Flexbox/Grid layouts, and responsive design.
- **PokéAPI** – Free RESTful Pokémon API used for data fetching.

## Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org) installed on your system.

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory**

   ```bash
   cd your-repo-name
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm start
   ```
   _(Note: If you used Vite, run `npm run dev` instead.)_

## What I Learned

- Fetching and handling asynchronous data using `fetch` and `async/await` in React.
- Managing loading and error states during API calls.
- Passing data cleanly between reusable React components via props.
- Styling dynamic elements (such as type badges) using pure CSS.
